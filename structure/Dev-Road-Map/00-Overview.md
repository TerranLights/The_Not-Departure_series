# Dev Road Map — Overview

This roadmap tracks development of [[Title TBN — "Departure"/"The
Not-Departure" are placeholders]], a 30+ episode audio drama reinterpreting
the 2013 ASMR series *Departure* into the Tepenian universe.

## How to read this roadmap
Files are numbered in dependency order — earlier phases unblock later ones.
Character work (Phase 2) comes before plot structure (Phase 4) comes before
theme (Phase 5), per this studio's standing Character → Plot → Theme
convention.

## Current state
**What's solid:** the core premise, the antagonist (Earthtech) and
resistance framing, four named main characters with drafted motivations/
goals/hardships (Doc, the Attendant, the Resistance Contact, the
Informant), and a rough 5-beat opening arc.

**What's incomplete:** exact dating (see 02-Blocking-Decisions.md), all
character/company/tech naming, the Mentor/Resistance-Contact lifespan math
(needs redoing under corrected dating), full episode-by-episode structure
beyond the first five beats, and any theme work.

## Guiding principles
- Character → Plot → Theme dependency order — theme is discovered from
  finished character/plot work, not designed up front (see
  07-Phase-5-Theme.md).
- No level-scaling, no clean endings — this studio's standing design law
  and "no good endings" tone principle both apply here as much as anywhere
  else.
- Stay consistent with established Cryptograph Helix and master-timeline
  canon; deviations are tracked as explicit blocking decisions, not
  silently assumed.

## Dependencies map
Phase 1 (Foundations) → Phase 2 (Characters) → Phase 3 (Supporting Cast,
parallel to 2) → Phase 4 (Story & Chapters) → Phase 5 (Theme, ungated) /
Phase 6 (World Depth, parallel to 2-5) → Phase 7 (Long-Term, after 4/5/6)
