# Phase 1 — Foundations

## Setting & timeline
- Universe: Tepenian, set 1-4 generations after *The Cryptograph Helix*'s
  close, well before *Outer Tepenia 1* — see 02-Blocking-Decisions.md for
  why the absolute year is still open.
- Destination: Saturn or beyond (not an exoplanet — see
  `../../Tepenian_Reinterpretation.md` §1 for why Gliese-581g-scale
  distance doesn't fit this stretch of the timeline).
- Key waypoint: Port of Phobos, the Bridge (experimental, Earthtech-
  controlled/adjacent jump tech).

## Naming conventions
- Placeholder names use `[[name TBN]]` inline, matching this studio's
  existing convention (see `../../background notes/cast of characters.md`).
- Model-coded robot characters keep their model code even once named (e.g.
  "[[Name]], STP-08"), matching the existing doll-folder naming convention
  (`TBN [Not-Departure Resistance Contact - STP-08]`).

## Structural/POV conventions
- Format: audio drama (radio-play style), not prose — no chapter/stanza
  prose conventions apply; episodes are the unit of structure (see
  `../main story/episode breakdowns/`).
- Projected length: 30+ episodes.
